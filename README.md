# Top-Quark Jet Tagging with Deep Learning

**Research Project**  
**Nikhef & University of Amsterdam (2026)**

## Overview

This repository contains a research project on **top-quark jet tagging** using the ATLAS Open Data dataset.

Starting from simple baseline models, several increasingly sophisticated deep learning architectures were developed and compared, including fully connected neural networks, convolutional neural networks (CNNs), graph neural networks inspired by ParticleNet, transformers and Lorentz-equivariant graph neural networks.

Training was carried out on datasets ranging from one hundred thousand to several million jets using the Dutch national supercomputer **Snellius**. The project investigated how model architecture and inductive bias influence performance in high-energy physics classification tasks.
